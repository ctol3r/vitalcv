## Rule

A continuity record is a dated checkpoint, not live telemetry. Before resuming work, verify current `main`, pull-request state, issue state, and the production `/api/version`. When the repository or fresh production evidence conflicts with a checkpoint, the fresher evidence wins and the record should be superseded or updated explicitly.
