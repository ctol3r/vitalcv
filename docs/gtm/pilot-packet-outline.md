# VitalCV Pilot Packet Outline

Timestamp: 2026-05-30 16:32 PDT (America/Los_Angeles)

Status: skeleton only. This is not polished sales copy and should not be sent externally without evidence review.

## Pilot

30-day PSV readiness pilot.

## Target Buyer

Healthcare credentialing, clinician recruitment, payer credentialing, staffing operations, or medical-staff services leaders who own time-to-start friction and primary-source review quality.

## Problem

Healthcare employers repeatedly re-check the same clinician facts because prior verification is not reusable or trusted across institutions. The pilot should measure whether an NPI-first source-readiness surface reduces ambiguity and review time without overstating what VitalCV can prove.

## NPI-First Workflow

1. Start with clinician NPI.
2. Read source-backed public data where available.
3. Separate source-backed, unavailable, gated, access-required, and institution-review-required states.
4. Show reviewer-ready source attribution and receipt-style evidence.
5. Record what remains blocked for institution review.
6. Measure whether the reviewer can move faster with less uncertainty.

## What VitalCV Does

- Starts from NPI rather than document upload.
- Shows source-backed readiness where source evidence exists.
- Makes source freshness, availability, and review boundaries visible.
- Produces reviewer-ready evidence views for the NPI/passport/review wedge.
- Helps identify what is ready, what is stale or unavailable, and what the institution must review itself.

## What VitalCV Does Not Claim

- Does not complete credentialing.
- Does not approve, clear, or hire clinicians.
- Does not replace institution review.
- Does not claim universal acceptance.
- Does not claim NPDB, DEA, ABMS, SAM.gov, Doximity, SOC 2, NCQA, or HIPAA certification unless separately integrated, audited, and proven.
- Does not promise instant starts; the target claim is reducing time-to-start from months toward days when the verified workflow supports it.

## Pilot Success Metrics

- Time from NPI entry to reviewer-ready evidence view.
- Number of source-backed fields available.
- Number of gated/unavailable fields clearly separated from source-backed fields.
- Reviewer time saved per clinician review.
- Ambiguous review items reduced.
- Days-to-start delta compared with the pilot team's baseline.
- Reviewer confidence, recorded as qualitative feedback with source-specific notes.

## Required Source Evidence

- NPPES read timestamp and source status.
- OIG/LEIE status and timestamp if available.
- PECOS status, freshness, and snapshot limitation if available.
- State-board lane status or access-required explanation.
- Explicit institution-review-required fields.
- Any gated source state labeled as gated, not source-backed.
