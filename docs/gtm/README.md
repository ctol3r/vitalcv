# VitalCV Founder Sales Kit

Practical, founder-led GTM assets for booking 30-day PSV Readiness Pilots. Every asset obeys the same rules:

* No guaranteed savings, no instant-hire claims, no fake customer traction, no fake ROI.
* No blockchain-first pitch. The trust container is explained as an audit record; cryptography is used for integrity, not as the product story.
* Limitations are always explicit: VitalCV is **PSV readiness + audit-ready proof + time-risk visibility**, not a CVO replacement and not a credentialing committee substitute.
* Every number used externally must come from a real measurement or be explicitly labelled as an internal simulation.

## Positioning the product (one paragraph)

VitalCV assembles a source-backed evidence packet from NPPES, OIG LEIE, PECOS public data, and a configured state-licensure lane, then exports it as a deterministic JSON / ZIP / PDF proof pack with an audit event on every export. It does not replace Primary Source Verification. It does not replace the credentialing committee. Partial evidence stays partial. The pilot converts "our application sat in a black box for weeks" into "we knew on day zero what was decision-grade, what was partial, and what needed PSV."

## When in doubt

* If a phrase sounds too good, check it against the banned-strings list in the `/pilot` page tests (`apps/web/__tests__/pilot-proof-page.test.tsx`). Same discipline applies to outbound copy.
* If a buyer pushes for "guaranteed savings" or "full automation," walk — or reframe to the readiness / visibility wedge.
* The pilot is free. The commercial conversation comes after we hand over a KPI report against the buyer's real baseline.
