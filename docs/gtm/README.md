# VitalCV Founder Sales Kit

Practical, founder-led GTM assets for booking 30-day PSV Readiness Pilots. Every asset obeys the same rules:

* No guaranteed savings, no instant-hire claims, no fake customer traction, no fake ROI.
* No blockchain-first pitch. The trust container is explained as an internal audit record; cryptography is used for integrity, not as the product story.
* Limitations are always explicit. VitalCV is **PSV readiness + audit-ready proof + time-risk visibility**, not a CVO replacement and not a credentialing committee substitute.
* Source claims are truthful:
  * NPPES confirms NPI identity and public registry fields, **not** license validity.
  * OIG LEIE is a federal check against the **latest available source release**, not a real-time OIG feed.
  * PECOS is **public Medicare FFS enrollment posture**, not the real-time PECOS portal.
  * **SAM.gov is not integrated yet; OIG LEIE is included.** NPDB self-query evidence **expires after 45 days** and is a future lane.
* Every number used externally must come from a real measurement or be explicitly labelled as an internal simulation.

## When in doubt

* If a phrase sounds too good, grep for it against the banned-strings regex in `apps/web/__tests__/pilot-proof-page.test.tsx`. The same discipline applies to outbound copy.
* If a buyer pushes for "guaranteed savings" or "full automation," walk — or reframe to the readiness / visibility wedge.
* The pilot is a small no-charge structured pilot. The commercial conversation only comes after we hand over a KPI report measured against the buyer's own baseline.
