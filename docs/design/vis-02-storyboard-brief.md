# VIS-02 — Five-Beat Storyboard Lab: Brief

**Wave:** CC-02 / VIS-02 (next; this brief is the CC-01 deliverable, not the wave itself)
**Authority:** Experience Constitution EC-25…EC-29 (Part V, added by CC-01) · UX-01 verdict (Direction B, amended) · `docs/design/vitalcv-cinematic-storyboard.md` (Z0 anatomy)
**Status:** Awaiting founder GO to run VIS-02. No production motion assets in this wave.

## What VIS-02 produces

Three HTML/SVG storyboard boards of the Journey Film — Identify → Build → Choose →
Apply → Carry forward — built in `design-lab/` (not `apps/web`), using abstract,
fictional content that passes the EC-25 truth review.

The UX-01 verdict already locked palette and type authority (Direction B with
amendments), so the three boards do **not** re-litigate direction. They explore
**register composition inside the verdict**:

1. **Dark operational** — the public dark register (`#141517` family) carrying the film.
2. **Light editorial** — the light register carrying the same five beats; tests whether
   the film survives on evidence-adjacent surfaces.
3. **Hybrid** — dark scene-world, light record-object; tests the register seam itself.

Each board must include: the protagonist object per Z0 anatomy (silhouette readable at
120px; portrait, never landscape) · the approval gate pause · the employer review
boundary that receives and never resolves green · a 390px mobile storyboard · the static
reduced-motion end frame · a transcript · and the layout showing the scene **beside** the
real NPI action, never in place of it.

## Review method

The five-second comprehension test, run cold: can a viewer identify (a) the profile is
owned by the clinician, (b) something waits for the clinician's approval, (c) the
employer makes its own decision — with all copy covered? A board that needs its captions
fails (Z0's test, now EC-27).

## Constraints carried from the constitution

- EC-25 truth review on every frame: no fake providers, counts, matches, verification,
  submission, or employer outcome.
- EC-28 placement: the Journey Film has **no homepage authorization**. VIS-02 explores
  the film for "How it works"-class surfaces; a homepage placement is a separate EC-22
  amendment with its own founder gate. Boards must not be composed as homepage heroes.
- EC-29 budgets apply to the eventual assets, not the boards; note them on each board.
- Design-lab work is exempt from the UI PR freeze (EC-0) because it ships nothing to
  `apps/web`.
