## Column meanings

- **NATIONAL ROUTE / DIRECT ROUTE** — `declared` means a route is defined in the router. It does **not** mean the route can execute. Execution requires RUNTIME STATE = `LIVE`.
- **RUNTIME STATE** — `NOT_IMPLEMENTED` (no adapter), `BLOCKED_ON_ACCESS` (adapter exists, access unresolved), `READY_UNPROVEN` (permitted but never run in production), `LIVE`.
- **LAST SUCCESS** — timestamp of a successful **production** run. Fixtures and sandbox runs never write this field.
- **DECISION GRADE** — `false` everywhere. Promotion to decision-grade is a separate gated wave.
- **DISCIPLINE AVAILABLE** — `UNKNOWN` means not established. It must never render as "no discipline found".
