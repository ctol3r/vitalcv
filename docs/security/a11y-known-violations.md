# A11Y Known Violations Whitelist

Violations listed here are accepted at the current foundation tier. Each entry requires:
- **Rule ID** — axe rule identifier
- **Route** — affected route or "all" for global
- **Justification** — why this is accepted now
- **Planned fix wave** — when this will be resolved

## Accepted violations

|---|---|---|---|
| `color-contrast` | all | Design system token contrast ratios are being audited and upgraded in the DS-contrast-1 wave. The graphite/midnight themes have known low-contrast combinations on secondary text. | Wave DS-contrast-1 |
