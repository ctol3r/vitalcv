02

Five rules of separation

every rule shifts in lockstep — no overlap states
Rule
A · Previewanonymous · exploratory
B · Snapshotauthenticated · owned
C · Signedinstitutional · anchored
Border
Dashed, 1.5px, slate-400. Reads as not committed to. Paper background (warm) breaks from the slate system, so the eye registers it as a different surface entirely.
dashed · paper
Solid, 1px, ink-900. The default authoritative line weight. White card on slate-50 page. Same border as every working document.
solid · 1px black
Solid + inversion. Border ink-950 + interior ink-950. Inverted register is reserved — used only for cryptographically signed surfaces.
inverted · reserved
Iconography
None. A dashed open square as the only glyph. No badge, no checkmark, no shield. Absence of mark = absence of authority.
Open ring with pulse. Live data indicator next to 14:32:08Z. The ring is unfilled — it represents reach, not signature.
Key glyph. A small key icon at the top, drawn in line weight. The only place a key appears in the entire system.
Motion
Typewriter caret. Headline ends with a blinking cursor — the page is still composing. Suggests “not yet a thing.”
Freshness pulse. The ring next to the timestamp breathes at 2.2 s. Confirms the session is live, the clock advancing.
None. The artifact is steady. Motion would undermine permanence. Signed = settled.
Labels & copy
Marketing register. “See what a provider passport looks like.” Serif body. Friendly. Footer: No account · nothing stored · refresh discards.
Operational register. “Dr. Mira Chen, MD” · NPI · session bar. Footer: Internal · not a credential. Honest about scope.
Institutional register. “Receipt · #48,214 · signed.” All mono. No prose. The form of a notarized document.
Metadata density
2 fields. NPI · sources. The minimum to show the shape.
6 fields + 3 lanes. checked_at · channel · ownership · replay · session · run_id. Enough to act on.
8 fields + signature footer. subject · issuer · alg · status · checked_at · prev · hash · run_id. Auditor-complete.
Hover · interaction
Hover surfaces a tooltip on every dashed element: not committed. Click anywhere → toast: sign in to bind this to you.
Hover a lane → expanded source row with last-fetched and tier. Hover the timestamp → tooltip with run_id full string + checked_at in local time.
Hover any field → tooltip with the field’s commitment status (“part of signed payload” vs “rendered metadata”). Click the key → flips to the verify panel.
What it asserts
Nothing about any real provider. Marketing artifact only.
A live, owned view by an authenticated session. Good for current decisions. Not portable.
A signed, anchored credential. Verifiable offline against did:web. Portable. Durable.
What a verifier should do
Nothing. Not actionable. Sample data.
Read in context. Live state is current. Don’t archive — the run_id rotates.
Download & verify. Hand to an auditor. Replay months later. Trust path goes around VitalCV.

Failure modes the register prevents

what would happen without the rules
Confusion
Without rulestypical SaaS UI
With rulesthis system
Why it mattersinstitutional cost
Preview → real
Demo screen looks identical to the real product. Users start treating sample data as authoritative within a session.
Paper bg + dashed border + caret + serif copy. Preview is unmistakably not the product.
Privileging decisions made against fake data are reportable events.
Snapshot → credential
Authenticated view exports as a screenshot. Recipient assumes it’s portable.
Snapshot has session bar, pulse, “Internal · not a credential” footer. Never reads as portable.
An employer relying on a screenshot has no replay path. CR §3 wants the receipt.
Signed → marketing
Credentials get hero treatment — large headlines, gradient panels, decorative geometry. Feels like a product page.
Signed register is inverted, dense, mono. It reads as a notarized document, not a product surface.
Auditors discount marketing surfaces by default. Density signals seriousness.
Degraded → silent
A stale source returns last-known value. UI shows a green check.
Snapshot lanes carry a dashed chip + age. Degraded states are visually surfaced, not hidden.
Silent degradation = institutional liability. The system would rather look honest than tidy.
