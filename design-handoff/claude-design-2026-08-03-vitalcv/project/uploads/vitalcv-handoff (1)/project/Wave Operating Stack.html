§1 · The four primary roles 04 columns
01

Claude Desktop

Supervisor

Holds the wave intent. Frames the brief, sets scope, and decides what is in and out of the wave.

  • ·Owns the wave brief and acceptance criteria.
  • ·Resolves direction when scope drifts.
  • ·Approves handoff to the next role.
  • ·Does not write code or final copy.
In: brief Out: scoped intent
02

Claude Code Terminal

Builder

Produces the working artifact from the scoped intent. Owns file structure, components, and integration.

  • ·Implements files, primitives, and views.
  • ·Reuses existing system; flags new patterns.
  • ·Returns a runnable artifact, not a draft.
  • ·Does not self-certify the output.
In: intent Out: artifact
03

Codex

Verifier

Independent review pass. Reads what was built against the brief and against truth-aligned copy rules.

  • ·Checks render, layout, and console.
  • ·Audits copy for unsupported claims.
  • ·Files findings; does not silently fix.
  • ·Cannot ship; only accept or reject.
In: artifact Out: verdict
04

Claude Design

Design Output Bundle

Final packaged output for the wave. Registers assets, captures the visual record, and closes the wave.

  • ·Registers the artifact for review.
  • ·Bundles screenshots and notes.
  • ·Hands a single deliverable to the supervisor.
  • ·Does not re-open the build.
In: verdict Out: bundle
§2 · Wave flow

One direction. No skips. Each role hands the next a single, named output.

01Supervisor
02Builder
03Verifier
04Bundle
→
⤴Re-scope
⤴Re-build
⤴Re-verify
A rejection at 03 returns to 02 with named findings. A scope conflict at 02 returns to 01. The bundle at 04 is only produced after a clean verdict.
§3 · Secondary tools

Browser / Cowork are optional. Bring them in only when a wave needs external reference, multi-window coordination, or a live handoff. They are not part of the default loop and do not replace any of the four primary roles.

§4 · Paused tools

OpenClaw is paused. Do not invoke it inside a wave unless explicitly restored by the supervisor in the brief. If a wave appears to need it, return to 01 and re-scope.
