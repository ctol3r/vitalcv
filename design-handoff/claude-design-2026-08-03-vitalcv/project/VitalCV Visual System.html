01

Visual North Star

Feeling · tone · first five seconds

If a chief credentialing officer opens VitalCV in a hallway between meetings, three things must be readable in five seconds: what is true today, what is sourced, what still needs them to decide. The screen should feel like an issued document — not a SaaS dashboard, not a hospital intranet, not crypto theater.

Paper. Ink. Hairline. Mono.

Paper, not glass. Warm off-white substrate, near-black ink, hairline rules. The screen reads like an issued page — quiet where it doesn't matter, dense where it does.

Evidence first, action second. Every field carries its source inline; the primary action only appears after the evidence is legible.

Quiet precision. Tabular numerics, monospace for metadata, deliberate whitespace, a single ink-indigo accent used surgically.

Calm in degraded states. Gaps are gray and labeled — never red. The product never sounds an alarm about a person.

None of the usual SaaS reflexes.

Not a hospital intranet. No teal gradients, no clipart caduceus, no portal chrome from 2004.

Not a fintech dashboard. No vanity charts, no green-arrow trust scores, no leaderboard energy.

Not crypto theater. No "chain-of-trust" animation, no node-graph poetry, no certificate seals.

Not generic SaaS. No gradient hero blob, no oversized rounded cards, no fake live counters, no glassmorphism.

02

Design Principles

Eight rules · every component obeys

A principle is only a principle if it can be violated. Each rule below has a corresponding component decision the system enforces, plus a one-line example of how the rule prevents a familiar SaaS reflex.

01

Evidence before action.

No button is offered until the value it acts on is legible with its source. Primary actions sit below the field, never above.

Never an «Approve» button next to a value with no source row.
02

One accent, used surgically.

Ink-indigo is reserved for the single most consequential affordance per screen. Status uses its own quiet palette — never the accent.

If two buttons compete for accent, one of them is wrong.
03

Hairlines, not boxes.

Structure is implied by 1px rules and whitespace, not nested rounded containers. Containers earn their border by holding state, not chrome.

If a card has only one child, dissolve the card.
04

Mono for proof, sans for prose.

Identifiers, timestamps, NPI numbers, hashes and receipts are monospace and tabular. Human language stays in Geist sans.

A receipt rendered in proportional type is not a receipt.
05

State, not story.

Trust language uses six paired tokens (verified, pending, blocked, contradicted, unknown, stale). No adjectives, no marketing tone, ever.

Never «Looking good!» — say VERIFIED 2026·05·12.
06

Calm in degraded states.

Missing data is labeled gray and self-explaining, never red. The system absorbs blame for itself, never about a person.

Source unreachable → SOURCE OFFLINE · last 02:14, not "ERROR".
07

Role speaks in tone, not color.

Clinician, verifier and operator surfaces share the palette but differ in density, copy, and what's primary. The product never «color-codes» people.

Same passport, different default actions per role.
08

Continuity over novelty.

Every screen carries the lineage strip: who said what, when, citing what. Navigation is a sequence of receipts, not tabs.

If you can't trace it, you can't trust it — surface the trace.

Aesthetic Benchmarks

References to study · not to copy

Where to look — and what specifically to take. Each benchmark is paired with the single quality we steal, not the whole gestalt.

S
For document-grade type and density

Stripe Press & Stripe Dashboard documentation

Steal · how technical detail is laid out as a printed page. Generous left rails, hairline rules, monospace identifiers inline with prose. Do not steal · the gradient hero.

L
For density at speed

Linear changelog & issue surfaces

Steal · keyboard primacy, command palette, restraint in motion. The way state lives in tiny chips. Do not steal · the gradient aurora chrome.

M
For receipt-grade calm

Mercury invoices & account statements

Steal · how financial truth is rendered as a quiet, printable document. Tabular numerics, mono for ids, paper-substrate neutrals. Do not steal · the green accent.

V
For paper-substrate web product

Vercel docs · Reading mode (Robin Sloan, NYT mag)

Steal · serif italic as the only emotional accent. Long-form rhythm in a product chrome. Do not steal · the dark blob illustrations.

N
For institutional voice

Notion enterprise · Retool admin · Plaid Console

Steal · how to look like infrastructure without looking severe. Quiet color, named states, monospace for system events. Do not steal · the indigo-heavy color saturation.

A
For zen sign-in experience

Apple ID · 1Password · Mercury login

Steal · passwordless-by-default, role-aware copy ("Continue as clinician"), the split-pane brand quote without giving the form to a hero illustration. Do not steal · the marketing hero.

Final Design Call

One paragraph · one signature
Issued 2026·05·26 · Design · D57

VitalCV ships as a document, not a dashboard.

The visual system stands on six commitments: paper substrate, near-black ink, hairline rules, one accent used surgically, monospace for proof, and six named trust states that absorb all color in the product. Everything else — surfaces, features, interactions — is rendered from this set. If a future screen cannot be built from these primitives, the screen is wrong, not the system.

Build in the order on §11. Hold the line on §02. Do not add a seventh state, an eighth principle, or a second accent.
