Six drift signals · detectable by inspection · fix before shippingdrift is never acceptable
Signal 01
UI copy references unbuilt feature
A button, label, or section heading describes a feature with no handler or backend.
Remove copy, add partial marker, or build the feature first.
Signal 02
Design artifact links to non-existent route
A nav link in a design spec points to a surface that has no live route.
Audit every nav link before porting from design to product.
Signal 03
Mocked data without // MOCK label
A hardcoded value in a live surface appears to be real data.
Add // MOCK to every hardcoded value. Connect or mark partial.
Signal 04
Superseded file still in router
An old wave file is still imported with an active route after a higher wave shipped.
Remove route from app.jsx. Add supersession comment. Update topology map.
Signal 05
Topology map stale after wave ships
Route binding table says Partial; the component is now complete. Map wasn't updated.
Treat topology map update as a required step 4 deliverable — not optional cleanup.
Signal 06
Design artifact linked from product nav
A D44–D55 HTML artifact is linked from the product's navigation bar or sidebar.
Remove all design artifact links from product navigation. Never import in app.jsx.

Route hygienebinding rules · per wave
Nav links
only link to live or partial routes · link to spec or orphaned surfaces
Supersession
Ship wave N → remove wave M route → add comment → update map. Three steps. Same commit.
Restoration
restore superseded file by removing comment · restoration = new wave number · always
Design artifacts
import D44–D55 HTMLs in app.jsx · link from product nav · documentation only
