Implementation rules for Claude Code
Copy grammar
1
Stage titles are declarative past tense when complete. "7 of 10 verified." not "Verification in progress." Period at end.
2
Source issues are recoverable by default. "DEA is checking again" not "DEA ARCOS degraded." Reserve "not responding" for extended gaps.
3
Timestamps are human-readable. "3 minutes ago" or "2:31 PM" — never raw UTC epoch. Use Intl.RelativeTimeFormat.
4
Action needed is always explicit. Every view must state: "No action required" or name the specific action. Never leave the operator guessing.
5
Ownership chip determines copy tone. own-sys → passive voice, automatic. own-rev → active, direct. own-org → read-only, submitted.
6
The next footer always has one primary action. Ghost link for secondary. No footer button = system is handling.
Attention queue algorithm
1
Priority 1 — Reviewer items with source issues (oldest stale result first)
2
Priority 2 — Reviewer items with results arrived, awaiting review (newest first)
3
Priority 3 — Reviewer items still running (most time elapsed first)
BG
Background (system items) — shown below the fold, no action button. Source issues + running status.
