In the deployments list, look for the entry with commit SHA eadac9bd on branch wave-10a/docs-status.

Status should be one of:

▲ Next.js [version]

Container starts + healthcheck passes
After build: container start logged. Look for:
▶ Starting Next.js server or ready - started server on 0.0.0.0:[port]

If Failed

If Railway build failed on eadac9bd

Do not modify anything. Do not change tsconfig, secrets, Railway settings, or DNS. Copy the last 40 lines of the build log exactly and send them in chat. Claude will identify the failing command and root cause.
→
How to copy Railway build logs
Railway → vitalcv-web → Deployments → click the failed deploy → Build Logs tab.
Scroll to the bottom. Copy from the last successful workspace build output to the final error line.
Include the exact failing command (usually a tsc or next build error with a file path).

What to look for specifically:
  • Any line containing error TS — TypeScript compile error
  • Any line containing Cannot find module
  • Any line containing vitest — means tsconfig exclude fix didn't propagate
  • The name of the @vitalcv/ package that failed
  • The exact file path that caused the error
