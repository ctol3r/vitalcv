Phase 04

Responsive & Accessibility QA

4 breakpoints · WCAG 2.1 AA baseline
Breakpoint Checklist
  • 1440px desktop — Full layout. Nav items visible. Hero full-width. No overflow.
  • 1280px laptop — Same as 1440. Check for horizontal scroll. Verify sidebar/grid behavior.
  • 768px tablet — Nav collapses or stacks gracefully. Card grid reflows. Touch targets ≥44px.
  • 390px mobile — Single column. Nav hamburger functional. CTA buttons full-width. No text overflow. Type ≥15px.
Type & Contrast
  • Body text: minimum 4.5:1 contrast ratio (WCAG AA)
  • Large text (>18pt/24px): minimum 3:1 ratio
  • Status tags and chips: verify contrast with background
  • Muted ink (--ink-400/500): check against white/paper backgrounds
  • Dark header text on --ink-950: must be ≥4.5:1
  • No text below 13px in body copy
  • Mono labels: check at 9–10px size — must remain legible
Keyboard & Focus
  • Tab order follows visual reading order
  • Focus ring visible on all interactive elements
  • Modal / drawer: focus trapped inside when open
  • Escape key closes modals and drawers
  • Skip-to-content link present on main pages
  • Clerk auth widget: keyboard nav functional
  • All CTAs reachable via keyboard
Layout Integrity
  • No horizontal overflow at any breakpoint
  • No clipped cards or hidden CTAs at mobile
  • Tables with many columns: horizontal scroll, not clipping
  • Long route strings / mono labels: word-break or truncation applied
  • Images: no broken src at any breakpoint
  • Sticky header stays above content on scroll
  • Footer visible and not cut off

Phase 05

Copy Safety Audit Framework

Banned phrases · replacement library · per-page risks
Unsafe → Safer Replacement Library
Unsafe (banned) Safer replacement Why unsafe Risk pages
Verified Source-confirmed Implies institutional acceptance or legal clearance VitalCV cannot provide. /, /holder, /verify, /passport
Cleared Ready for institution review "Cleared" implies a background check or regulatory outcome. /, /holder, /clinician
Approved Review-ready Implies an institution has made a formal acceptance decision. /, /employer, /verify, /dossier
Accepted everywhere Designed for reusable evidence review No credential is accepted "everywhere." Misleads both clinicians and employers. /, /holder, /pricing
Tamper-proof Cryptographically anchored "Tamper-proof" is a falsifiable absolute claim; no system qualifies. /trust, /trust/attribution
Fully automated Workflow-assisted Implies no human review, which contradicts the institutional ownership model. /, /employer, /pricing
Instant onboarding Designed to reduce review time Credentialing timelines are institution-controlled. VitalCV cannot guarantee speed. /, /holder, /employer
Continuously monitored Evidence refreshed on submission Unless real-time monitoring infrastructure exists and is live, this is a false claim. /status, /trust
Blockchain makes it safe Cryptographic anchoring provides audit traceability Blockchain does not validate the truth of underlying data. Misleads technically. /trust, /trust/attribution
Guaranteed credentialing Evidence-bounded credential readiness No credentialing outcome can be guaranteed; institutions retain final authority. /, /holder, /pricing
Audit-ready = compliant Audit-ready artifact for institution review Compliance determinations belong to the institution, not VitalCV. /trust, /trust/attribution
Trusted by [institution] Designed for institutional review workflows Only use if real relationship exists. Unconfirmed trust logos are a liability. /, /employer
Trustless Evidence-anchored "Trustless" is a crypto term that confuses non-technical audiences and overstates. /trust
Safe Language Patterns
Evidence claims
  • "Evidence received from source"
  • "Source-confirmed documentation"
  • "Evidence-bounded status"
  • "Attribution-bounded record"
  • "Generated from available source evidence"
Readiness claims
  • "Ready for institution review"
  • "Review-ready artifact"
  • "Audit-ready packet"
  • "Designed to reduce review time"
  • "Evidence packet for credentialing review"
Status claims
  • "Requires institution review"
  • "Institution review ownership retained"
  • "Evidence received — review required"
  • "Source-confirmed, not institution-cleared"
  • "Pending institution determination"
Hard rule: Any copy that implies an institution has already accepted, approved, or cleared a provider is a launch blocker. This includes testimonials, case studies, or logos that imply institutional endorsement without a confirmed relationship.
