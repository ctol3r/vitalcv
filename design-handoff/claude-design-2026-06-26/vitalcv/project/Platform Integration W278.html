Wave 278 · platform integration · no new features · no new pages · no new subsystems · only integration

Four streams. One platform.

VitalCV shipped as four self-standing products — Wallet, Mobility, Organizations, Opportunities — each with its own shell, its own navigation model, its own wave number, and no way to cross between them. Every stream is sound. The seams between them are the problem. Wave 278 adds nothing new: it draws one navigation model, names one place every user starts, traces the clinician across all four, and removes every surface that exists twice. The test is simple — VitalCV should feel like one platform, not four projects merged.

W278·D1

Platform navigation — one model

create

One shell wraps all four streams. A single dark op-bar (subject + ledger state, stated once), a single brandmark, and one global nav whose primary destinations are the four streams — entered from a home. Each destination keeps its existing surfaces, demoted to a contextual sub-nav that only appears when you're inside it. Nothing is rebuilt; the streams are mounted under one chrome instead of four.

W278·D2

Career OS — the one entry point

build

Where does every user start? Career OS. Not the Wallet, not a stream — a home that shows who you are, your one career-health read, where you left off, and four doors into the streams. It is the answer to "what is this platform," given in a single screen. Every stream is reachable in one click; nothing here is a new feature — it is the existing reads, composed once.

Boundaries — what integration must not do
Hold the line 01
No new features
Every surface in W278 already ships in a stream. The work is composition, not creation.
Hold the line 02
No new pages
Career OS reuses existing reads. The dedup reduces page count; it never adds one.
Hold the line 03
No new subsystems
One router, one shell, one chrome. The streams keep their data models untouched.
Hold the line 04
Demote, don't delete
Duplicated concepts get one home and a contextual view — the concept survives, the copy of it doesn't.
