D5 · 01 · Semantic correctionColor

Sky implies info / success in every enterprise UI an operator has seen — Stripe, Linear, AWS console. Painting access required or gated in sky reads as "this is fine."

Anything that needs an operator to do something — accessRequired, gated, degraded, throttled, unreachable — uses the same amber. Cleared lanes use ink. There is no sky anywhere in the panel.

OK
ink-900 border + mark. Used only when a probe returned a useable answer.
WARN
amber #92400e on #fef3c7. Used for degraded, accessRequired, gated, unreachable.
FAIL
red #991b1b. Reserved for hard failures only. Not for throttling.
D5 · 02 · Hint typographyType

Remediation hints were rendering as text-[9.5px] — illegible at the distances operators actually sit from their monitors.

Bumped to text-[11px] with leading-snug (1.35) and mt-1 separation from the lane name. Hint sits on the full row width — never crammed into a chip column.

D5 · 03 · Retry context, no new CTACopy

The panel never adds a "Retry now" button next to a degraded lane — that invites the operator to thrash a source that's already throttling.

Instead, every warn row carries three facts in plain language: what failed, when it last worked, what the system is doing on its own.

Pattern
[What failed.] Last successful poll Nm ago. Retrying every Ns.
Tone
The operator is told the system has it — they're not invited to intervene unless a queued lookup actually needs them.
Exception
accessRequired + gated are the only states that name an actor: "Employer invocation required" / "Lift gating in admin".
