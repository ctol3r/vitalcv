The states VitalCV uses

Eight · paired with source & time

Every field in VitalCV resolves to one of eight states. Each pairs an ink color with a source name and a timestamp — never a bare word, never a score.

Source-backedABMS · 14d

Two or more public sources agree within freshness window.

Pending sourceCA Board · retry 02:14

Source queued for read or temporarily unreachable.

Source unavailableSAM.gov · offline 02h

A source we usually consult is offline. Not the clinician's failure.

Self-reportedclinician · 2026·04·22

Stated by the clinician — not yet backed by an external source.

Institution must reviewNPDB · institution-only

Source is institution-gated. Outside VitalCV's read scope.

Sanction recordedOIG LEIE · 2026·05·26

Sources disagree

Two sources return different values. Reconcile, never auto-merge.
