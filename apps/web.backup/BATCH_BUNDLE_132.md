## **Implementation Notes**

### **Technology Stack Alignment**

- **Framework**: Next.js 15 (App Router)
- **UI Library**: React 19
- **Styling**: Tailwind CSS 4 + CSS Layers
- **Animations**: Framer Motion 12
- **State**: SWR + React Context
- **Storage**: IndexedDB + localStorage
- **Workers**: Web Workers + Service Workers
- **Crypto**: Web Crypto API
- **Visualization**: D3.js + Three.js
- **Components**: Radix UI + shadcn/ui
- **Testing**: Playwright + Jest

### **Key Adaptations from iOS Bundle**

1. **Native APIs → Web APIs**
   - CoreAnimation → CSS Animations + Framer Motion
   - Keychain → Web Crypto API + IndexedDB
   - Haptics → Vibration API
   - Camera → WebRTC MediaStream

2. **Platform Patterns**
   - App Clip → Progressive Web App (PWA)
   - SwiftUI → React Server Components
   - Combine → SWR + React Query

3. **Performance**
   - Layout caching → React.memo + useMemo
   - Image optimization → next/image
   - Background jobs → Service Workers

**Phase A (Execution)**: Core functionality, directly buildable
**Phase B (Conceptual)**: Design system, UX theory, trust metaphors
**Phase C (Agents)**: Automation, linting, testing infrastructure
