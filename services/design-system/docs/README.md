# Design System Documentation

This directory contains documentation for the design system.

## Files

- `accessibilityTheming.md` - Accessibility guidelines for theming
- `generateThemingDocs.ts` - Script to generate theme documentation

## Generating Theme Docs

Run the documentation generator:

```bash
npm run docs:generate
```

This will generate markdown files for each theme in the `themes/` subdirectory.

## Theme Documentation

Generated theme documentation includes:

- Color tokens and swatches
- Typography scale
- Spacing scale
- Border radius values
- Shadow definitions
- Breakpoint definitions
